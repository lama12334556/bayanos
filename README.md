# بيانوس | Bayanos

**أداة تحوّل ملف Excel أو CSV إلى تقرير منسّق خلال ثوانٍ، بالعربي والإنجليزي.**
**Turn an Excel or CSV file into a finished report in seconds, in Arabic and English.**

🔗 **التجربة | Live demo:** https://lama12334556.github.io/bayanos

## المميزات | Features
- مؤشرات رئيسية واتجاهات ورسوم بيانية تلقائية | Automatic KPIs, trends and charts
- فحص جودة البيانات: قيم مفقودة، قيم شاذة، تواريخ غامضة | Data-quality checks: missing values, outliers, ambiguous dates
- تعرّف على أنواع الأعمدة والمعرّفات والتواريخ (بما فيها الهجري تقريبيًا) | Column-type detection, IDs and dates (Hijri approximated)
- يدعم xlsx وcsv وxls | Supports xlsx, csv and xls
- واجهة ثنائية اللغة تدعم RTL/LTR | Bilingual RTL/LTR interface
- **الخصوصية:** الملف يُعالج داخل المتصفح ولا يُرفع لأي مكان | **Privacy:** files are processed in your browser and never uploaded

## التقنيات | Tech
HTML, CSS, JavaScript (بدون إطار عمل | no framework). قراءة xlsx مدمجة، ومكتبة SheetJS فقط للملفات القديمة xls.

## حدود المشروع | Limitations
- التحليل تلقائي وبسيط (إحصاء وصفي)، وليس نمذجة أو تنبؤ | Analysis is automatic and descriptive, not modelling or forecasting
- التحويل من الهجري تقريبي | Hijri conversion is approximate
- اختُبر بشكل رئيسي على Chrome | Mainly tested on Chrome
- استُخدمت أدوات ذكاء اصطناعي في التطوير | Built with AI assistance

## الخطط القادمة | Roadmap
- تنبؤات بسيطة | Simple forecasting
- تصدير التقرير كـ PDF | PDF export
